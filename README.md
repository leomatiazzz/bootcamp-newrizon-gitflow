# Bootcamp-newrizon-gitflow

Repositório de demonstração prática sobre controle de versão e fluxo de trabalho com **Gitflow**, desenvolvido durante o bootcamp da **Newrizon**.

---

## Sobre o projeto

O projeto consiste em uma landing page moderna que apresenta a jornada de aprendizado no bootcamp, destacando conceitos de desenvolvimento, boas práticas de versionamento e evolução técnica contínua.

---

## Tecnologias utilizadas

- **HTML5:** Estruturação semântica da página
- **CSS3:** Estilização com flexbox, grid responsivo e identidade visual da Newrizon
- **Git & GitHub:** Controle de versão, histórico de commits e pull requests
- **Gitflow:** Estratégia de ramificação para desenvolvimento organizado em equipe
- **VS Code:** Ambiente de desenvolvimento e edição de código

---

## Estrutura do gitflow

O repositório segue a padronização do gitflow com a seguinte organização de branches:

- `main`: Código estável e pronto para produção
- `develop`: Branch principal de integração e desenvolvimento
- `feature/*`: Branches temporárias para implementação de novas funcionalidades (ex: `feature/tecnologias-e-contato`)

### Fluxo de contribuição:
1. Criar a branch de funcionalidade a partir da `develop`
2. Realizar alterações com commits semânticos e padronizados (*Conventional Commits*)
3. Abrir pull request direcionado para `develop` com solicitação de revisão de código (*code review*)

---

## Como visualizar o projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/leomatiazzz/bootcamp-newrizon-gitflow.git
   ```
2. Acesse o diretório:
   ```bash
   cd bootcamp-newrizon-gitflow
   ```
3. Abra o arquivo `index.html` em qualquer navegador web.
